一日聚项目 ​

项目结构

  • 使用 Fast API 做后端
  • uni-app + Vue 做 后台管理系统 和 微信小程序

第一 ​

感觉累 ​

虽然使用的是Agengt deepseek harness和Workbuddy 混合使用但是还是挺难描述的整个项目我个人感觉是挺复杂的

  • 第一个就是这个肯定是需要使用微信支付接口的(这一部分我还没有接触过暂时没有写)

  • 有需要有分销功能简单的二级分销功能简单又复杂商品添加分销的规则每一个SKU添加不同的分销额度

  • 邀请功能

    • 1分享邀请连接功能
    • 2分享邀请二维码功能
    • 3分享页面需要带邀请者的参数

  • 订单添加待确认功能 还要商家能够查看订单详情

    其实一开始做这个项目的时候我考虑到了
    都做了这还功能的，但是第一次查看我做的给我来一句暂时不用
    服了、现在加回去。不过还是得自己测试
    测试多次才行，不然下次展示不得炸了啊

第二 ​

了解业务 ​

总的来说理解了一个项目不只是需要代码还需要设计流程

1.整个界面是怎么走的

2.界面需要哪些信息（固定+后端返回）

3.资金怎么流动的（每一笔钱都需要严谨的流动信息）不能少也不能多

4.代码不是最重要的 最重要的是解决问题

或者说是解决需求-根据需求来制定计划通过代码逻辑来解决具体的需求
